# Арканоид

Браузерная аркада: 14 уровней, капсулы с бонусами и четыре темы. Игра открывается как обычный статический сайт — без сборки. На GitHub Pages она доступна по адресу [celeboeb.github.io/arkanoid](https://celeboeb.github.io/arkanoid/).

## Как играть

Нажмите **Играть** или выберите открытый уровень. Мяч стартует на ракетке: пробел, щелчок или короткое касание запускают его. Сбейте все разрушаемые кирпичи, чтобы перейти дальше. Серые металлические блоки не ломаются — из них строится каркас уровня.

Жизней в начале три. Капсулы падают из кирпичей. Рекорд, открытые уровни и настройки запоминаются в браузере.

### Бонусы

| Капсула | Эффект |
| --- | --- |
| ↔ | Широкая ракетка |
| ×3 | Ещё два мяча |
| Л | Лазер |
| М | Медленный мяч |
| К | Липкая ракетка: мяч прилипает, пока его снова не запустят |
| +1 | Дополнительная жизнь |
| – | Редкая узкая ракетка |

Кирпичи бывают обычными, крепкими (две или три трещины) и взрывными: взрыв задевает соседей.

## Управление

- **Мышь** — ракетка сразу следует за курсором.
- **Палец** — сдвиг в сторону. Точка касания не обязана попадать в ракетку, поэтому на телефоне палец не закрывает мяч.
- **Клавиатура** — `←` `→` или `A` `D` (работает и при русской раскладке). Ускорение плавное, с ограничением скорости.
- **Пробел**, щелчок или короткое касание — запуск мяча.
- **Esc**, `P` или кнопка **Пауза** — пауза. Если свернуть вкладку, партия тоже встаёт на паузу.
- **Чувствительность** в настройках меняет силу сдвига пальцем и разгон с клавиатуры.

Угол отскока от ракетки зависит от места удара: центр отправляет мяч круто вверх, край — полого в сторону. Скорость ракетки слегка подкручивает мяч. Мяч не уходит в почти горизонтальный полёт и не застревает в вертикальной «трубе»: угол ограничен. Внутри уровня он постепенно ускоряется, но не быстрее потолка.

## Темы

Тема переключается в **Настройках** в любой момент, партия не сбрасывается.

- **Неоновый ретро** — тёмная сетка, светящиеся кирпичи, след мяча.
- **Классика 80-х** — крупные кирпичи, полосы кинескопа, прямоугольные звуки.
- **Космос** — туманность, звёзды, ракетка-тарелка.
- **Минимализм** — светлый фон и плоские пастельные блоки.

Звуки синтезируются в браузере, отдельные файлы не скачиваются. В настройках можно выключить звук, изменить громкость, скорость мяча («спокойно», «норма», «быстро») и вибрацию на телефоне.

## Установка на телефон

Сайт — PWA. В Safari: «Поделиться» → «На экран Домой». Обновления подхватываются номером версии в адресах скриптов и в service worker: при сети телефон получает свежие файлы, без сети игра открывается из кэша.

## Локальный запуск

Положите файлы так, как их отдаёт GitHub Pages: корень сайта — это корень репозитория, а путь страницы — `/arkanoid/`.

```bash
npm install
npm run serve
```

Игра откроется на [http://127.0.0.1:4173/arkanoid/](http://127.0.0.1:4173/arkanoid/).

## Тесты

```bash
npm test
npm run test:e2e
```

`npm test` гоняет физику без браузера: быстрые подачи не проходят сквозь кирпичи и ракетку, мяч не застревает, угол остаётся в допустимых пределах, все 14 уровней проходимы.

`npm run test:e2e` поднимает тот же статический сервер и открывает `/arkanoid/` в Chromium, WebKit и мобильном WebKit.
